# 03 · 浏览与数据

适用版本：0.1.0 ｜ 更新于 2026-10-10

## 树与选择

- 展开连接 → 数据库 → 表；表名多时用树顶部的筛选框即时收敛。
- PostgreSQL / PgVector 有 schema 维度，树上方会出现可筛选的 schema 下拉，切换会同时清空已选表。
- 左侧选中数据库后，顶栏工具区的「数据库同步 / 数据库备份」解除置灰；选中表后「数据导出」解除置灰。
- 切换数据库时右侧不会停留在上一个库的内容：先显示加载页，旧请求的响应会被丢弃。

## 数据网格

| 能力 | 说明 |
| --- | --- |
| 分页 | 底部显示 共 N 行 · 查询耗时 · 当前库；「每页」可选 20 / 50 / 100 / 200（可筛选下拉），也可输入页码跳转 |
| 排序定位 | 行号列只作展示，不代表主键顺序 |
| 插入 | 页签右上「+ 插入」，按字段列表逐项填写；空字符串字段不会写入 |
| 编辑 | 行内操作或右键「编辑该行」；主键字段置灰不可改（ES 的元字段同样只读，见 [05](05-non-sql-engines.md)） |
| 删除 | 行内删除有二次确认弹窗 |
| 刷新 | 重新拉取当前页 |

## 写操作一定回显

所有写操作都显示后端返回的消息，而不是只提示「成功」：

- SQL：显示影响行数等信息；
- Redis：写入后会按主键回读该键并展示当前值，确认落到哪个键；
- Elasticsearch：写完会刷新索引，因此**新数据立刻能在列表里看到**，不需要手动刷新一次；
- 同步 / 迁移：执行后在弹窗里给出逐表结果，见 [06](06-sync-and-migration.md)。

失败时错误原文（含数据库返回的错误码与消息）会显示在通知条并写入日志。

## SQL / 命令页签

中部第三个页签按引擎改名（SQL / 命令 / REST / 查询）。输入框支持 `Ctrl + Enter` 执行，执行记录按当前库保留，可点历史项回填到输入框，也可一键清空。

## 危险操作

删除行、删除字段、删除索引、清空数据等入口在悬停提示里写明后果；ES / Redis 的「常用操作」清单里破坏性条目用红色描边区分，点击只是填入输入框，**不会自动执行**。
