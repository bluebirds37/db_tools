# 03 · 浏览与数据

适用版本：0.1.0 ｜ 更新于 2026-10-14

## 树与选择

- 展开连接 → 数据库 → 表；表名多时用树顶部的筛选框即时收敛。
- PostgreSQL / PgVector 有 schema 维度，树上方会出现可筛选的 schema 下拉，切换会同时清空已选表。
- 左侧选中数据库后，顶栏工具区的「数据库同步 / 数据库备份」解除置灰；选中表后「数据导出」解除置灰。
- 切换数据库时右侧不会停留在上一个库的内容：先显示加载页，旧请求的响应会被丢弃。

## 数据网格

| 能力 | 说明 |
| --- | --- |
| 分页 | 底部显示 共 N 行 · 查询耗时 · 当前库；「每页」可选 20 / 50 / 100 / 200（可筛选下拉），也可输入页码跳转 |
| 排序定位 | 行号列只作展示，不代表主键顺序 |
| 插入 | 页签右上「+ 插入」，按字段列表逐项填写；空字符串字段不会写入 |
| 编辑 | 行内操作或右键「编辑该行」；主键字段置灰不可改（ES 的元字段同样只读，见 [05](05-non-sql-engines.md)） |
| 删除 | 行内删除有二次确认弹窗 |
| 刷新 | 重新拉取当前页 |
| 筛选 / 排序 | 顶栏「筛选 & 排序」，见下一节 |

## 表节点的右键菜单

在左侧表列表里右键某张表：

| 菜单项 | 行为 | 备注 |
| --- | --- | --- |
| 打开表 / 刷新数据 / 复制表名 | 常规操作 | — |
| 导出 CSV / Excel | 打开导出对话框，可配列级脱敏 | 见 [07](07-export-mask-backup.md) |
| 转储表 (.sql) | 结构 + 数据转成 `.sql` | 仅 SQL 引擎 |
| 导入 CSV / Excel… | 打开导入对话框，目标表已填成这张表 | 表不存在时可勾选自动建表 |
| 清空表数据… | 删掉全部行，表结构保留 | **红色危险样式的二次确认** |
| 删除表… | DROP 掉表 | **红色危险样式的二次确认** |
| 同步到其他库… | 单表同步，可跨引擎 | 见 [06](06-sync-and-migration.md) |

- 清空与删除都必须再点一次确认才会执行，确认文案里写明**库名、表名和行数估计**（例如「`trading_agents` 里的 users 将删掉全部数据（约 1,284,321 行），表结构保留」），点「取消」什么都不会发生。
- 执行完把后端原话显示在通知条（如「已清空 users（TRUNCATE，影响 1284321 行）」「已删除表 orders」）；删表后表列表自动刷新，正在看的那张表被删就回到未选状态。
- 各引擎走各自的原生操作：SQL 是 `TRUNCATE` / `DROP TABLE`；MySQL 的表被外键引用时 `TRUNCATE` 会被拒，自动退化成 `DELETE`，并在消息里写明用的是哪种；PostgreSQL 遇到外键**直接把数据库的报错原样显示**，不替你猜。MongoDB 用 `delete` / `drop` 命令（文案是「集合」），Elasticsearch 用 `_delete_by_query` + refresh 与 `DELETE /索引`（文案是「索引」），Qdrant 用点位删除与集合删除。Redis 的「表」只是键类型分组，所以它的表节点**不出现**导入 / 清空 / 删除项。

## 筛选 & 排序

不写 SQL 也能只看待符合条件的行。MySQL / PostgreSQL / PgVector / SQLite 的表数据页顶栏有这个按钮，面板里一行一个条件：

**启用勾选 · 并且/或者 · 字段 · 运算符 · 值**

- 字段与运算符都是可键入筛选的下拉；运算符按字段类型给，数字列不会给出「包含」这类选项：
  - 文本：等于、不等于、包含、不包含、开头是、结尾是、在列表中、为空、不为空
  - 数字：等于、不等于、大于、大于等于、小于、小于等于、介于（两个值框）、在列表中、为空、不为空
  - 日期：等于、晚于、早于、介于、为空、不为空
  - 布尔：为真、为假、为空、不为空
- 值只当字面量：数字类型不加引号，文本里的单引号自动翻倍，所以 `O'Brien` 直接填就能查；「在列表中」用逗号分隔，中英文逗号都认。
- 多个条件按界面顺序逐层加括号，`(A OR B) AND C` 就是你排出来的样子，不受 SQL 优先级影响。
- 点「应用筛选 排序」才会查询，草稿怎么改都不偷偷重查；按钮上的数字是已生效的条件数，没填值的行不产出条件（会给出提示）。底部的「共 N 行」和分页都基于筛选后的结果。
- 排序可以在面板里点 `+` 加准则（升序 A→Z / 降序 Z→A），也可以**直接点表头**：升序 → 降序 → 取消，点表头立即生效。
- 「清除」一次丢掉所有条件与排序，回到全表。

Redis / Elasticsearch / MongoDB / Qdrant 用各自的命令、REST、查询页签取数，见 [05](05-non-sql-engines.md)。

## 写操作一定回显

所有写操作都显示后端返回的消息，而不是只提示「成功」：

- SQL：显示影响行数等信息；
- Redis：写入后会按主键回读该键并展示当前值，确认落到哪个键；
- Elasticsearch：写完会刷新索引，因此**新数据立刻能在列表里看到**，不需要手动刷新一次；
- 同步 / 迁移：执行后在弹窗里给出逐表结果，见 [06](06-sync-and-migration.md)。

失败时错误原文（含数据库返回的错误码与消息）会显示在通知条并写入日志。

## SQL / 命令页签

中部第三个页签按引擎改名（SQL / 命令 / REST / 查询）。输入框支持 `Ctrl + Enter` 执行，执行记录按当前库保留，可点历史项回填到输入框，也可一键清空。

## 危险操作

删除行、删除字段、删除索引、清空数据等入口在悬停提示里写明后果；ES / Redis 的「常用操作」清单里破坏性条目用红色描边区分，点击只是填入输入框，**不会自动执行**。
