# 08 · AI 智能体

适用版本：0.1.0 ｜ 更新于 2026-10-10

右侧面板（顶栏机器人图标收起 / 展开）用自然语言操作数据库：列连接、查表结构、执行 SQL、增删改数据、写长期记忆。

## 模型配置：多套 + 一个默认

「设置 → 大模型」里可以保存任意多套配置，**只有一条是默认**：

| 操作 | 说明 |
| --- | --- |
| 下拉切换 | 列出所有配置，副标题显示「默认 · 模型名」，可键入筛选 |
| 新增 | 以当前配置为模板复制一份（改名称与 Key 后保存） |
| 设为默认 | 已是默认时按钮置灰；切换默认会自动取消旧默认，保证「恰好一条默认」 |
| 删除 | 两段式确认；删掉默认配置后自动把剩下的一条提为默认 |
| 名称 | 「配置名称」就是切换列表里显示的名字，留空则显示「模型名（协议）」 |
| 测试 API | 用当前表单里的内容（未保存也算）真实请求一次，成功显示返回，失败显示原始错误 |

每套配置的字段：协议（OpenAI 兼容 / Anthropic）、Base URL、API Key、模型、温度、最大 tokens、接口模式（Chat Completions / Responses）、响应模式（自动 / JSON Object）、是否启用数据库工具、系统提示词。

保存校验只有两条硬要求：Base URL 与模型名不能为空。

## 对话里切换模型

面板顶部有「模型」下拉：

- 打开面板时自动读取配置列表，选中顺序是 **上次你选的 → 默认那条 → 第一条**；你选的记在本机，下次进来还在；
- 某条配置没填 API Key 时，下拉右侧出现「缺 API Key」提示，发送前就能看见；
- 右侧的刷新按钮重新读取配置列表（在设置里改完不用重启）；
- 读取中禁用下拉并显示「读取配置…」，失败时说明原因而不是留空白。

发送的消息会带上当前选中的配置；如果那条配置已经被删除，后端自动回落到默认配置而不是报错。缺 Key 时报错会点名是哪条配置。

## 工具调用与上下文

- 开启工具后，模型可以直接调用「列连接 / 列库表 / 查结构 / 执行 SQL / 读写数据 / 记忆」等工具；判断为数据库操作意图时会自动强制开启工具。
- 模型没有按协议输出工具调用时，会从文本里解析 `tool_name(key=value, ...)` 形式的调用作为兜底。
- 对话历史过长时自动压缩上下文再发送。

## 历史与记忆

- 「历史对话」可折叠，支持按标题与消息内容搜索，展开可看单条会话内容，删除有二次确认；
- 长期记忆在面板底部列出，可新增 / 删除；模型配置、连接、会话与记忆都存在 `~/.db_tools/`。
