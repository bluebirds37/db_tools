# 08 · AI 智能体

适用版本：0.1.0 ｜ 更新于 2026-10-14

右侧面板（顶栏机器人图标收起 / 展开）用自然语言操作数据库：列连接、查表结构、执行 SQL、增删改数据、写长期记忆。

## 模型配置：多套 + 一个默认

「设置 → 大模型」里可以保存任意多套配置，**只有一条是默认**：

| 操作 | 说明 |
| --- | --- |
| 下拉切换 | 列出所有配置，副标题显示「默认 · 模型名」，可键入筛选 |
| 新增 | 以当前配置为模板复制一份（改名称与 Key 后保存） |
| 设为默认 | 已是默认时按钮置灰；切换默认会自动取消旧默认，保证「恰好一条默认」 |
| 删除 | 两段式确认；删掉默认配置后自动把剩下的一条提为默认 |
| 名称 | 「配置名称」就是切换列表里显示的名字，留空则显示「模型名（协议）」 |
| 测试 API | 用当前表单里的内容（未保存也算）真实请求一次，成功显示返回，失败显示原始错误 |

每套配置的字段：协议（OpenAI 兼容 / Anthropic）、Base URL、API Key、模型、温度、最大 tokens、接口模式（Chat Completions / Responses）、响应模式（自动 / JSON Object）、是否启用数据库工具、系统提示词。

保存校验只有两条硬要求：Base URL 与模型名不能为空。

## 对话里切换模型

面板顶部有「模型」下拉：

- 打开面板时自动读取配置列表，选中顺序是 **上次你选的 → 默认那条 → 第一条**；你选的记在本机，下次进来还在；
- 某条配置没填 API Key 时，下拉右侧出现「缺 API Key」提示，发送前就能看见；
- 右侧的刷新按钮重新读取配置列表（在设置里改完不用重启）；
- 读取中禁用下拉并显示「读取配置…」，失败时说明原因而不是留空白。

发送的消息会带上当前选中的配置；如果那条配置已经被删除，后端自动回落到默认配置而不是报错。缺 Key 时报错会点名是哪条配置。

## 取数范围：先选库，再提问

模型行下面是「范围」一行：**连接 + 数据库**两个可键入下拉，右边是「跟随左侧浏览」（准星图标）与「清除」。

- 选好之后范围**记在这条会话上**（存在 `chat_sessions.json`），换会话各用各的，关掉重开还在；
- 「跟随左侧浏览」一次把左侧树上当前选中的连接 / 库 / 表搬过来，表会以「当前表 xxx」的标签显示，不想带就点「不带上表」；
- 范围会写进系统提示词，同时工具调用的 `connection_id` / `database` / `table` **缺省就按范围补齐**——所以「查这张表前 10 条」这类话不用先让模型去翻连接列表；
- 没选范围时照旧：模型自己调 `list_connections` 问你要，工具缺连接时会明确回「尚未确定连接」而不是瞎猜；
- 换连接会清掉库与表；库列表读取中下拉显示「读取库…」，读不到时给出说明而不是一片空白。

## 图片提问（多模态）

输入区左侧是图片按钮，也可以**直接粘贴截图**或把图片拖进输入区。

| 约束 | 值 |
| --- | --- |
| 一条消息最多 | 4 张 |
| 单张上限 | 8 MB |
| 接受格式 | png / jpeg / gif / webp / bmp |

- 待发图片显示为缩略图，右上 × 移除；超出数量会说明忽略了几个，非图片文件与超大文件各有明确提示；
- 只有图没有文字也能发送；发送按钮在带图时会写明「发送（含图片）」；
- 图片按文件存到 `~/.agentdb/ai_images/`，会话 JSON 里只存文件名，所以历史对话回看仍有图，删除会话会一并清掉这些文件；
- 追问时最近 4 张历史图片会随本轮重新附带（模型不会记住上一轮的图），更早的只在文本里注明本轮没再附带；
- 点缩略图放大查看，Esc 或点空白关闭；
- 请求体按协议自动编排：OpenAI Chat Completions 用 `image_url` 的 data URL，Responses 用 `input_image`，Anthropic 拆成 `base64` 的 `media_type` + `data`。模型不支持图片时，返回的错误原文会直接显示在通知条里。

## 工具调用与上下文

- 开启工具后，模型可以直接调用「列连接 / 列库表 / 查结构 / 执行 SQL / 读写数据 / 记忆」等工具；判断为数据库操作意图时会自动强制开启工具。
- 模型没有按协议输出工具调用时，会从文本里解析 `tool_name(key=value, ...)` 形式的调用作为兜底。
- 对话历史过长时自动压缩上下文再发送。

## 历史与记忆

- 「历史对话」可折叠，支持按标题与消息内容搜索，展开可看单条会话内容，删除有二次确认；
- 长期记忆在面板底部列出，可新增 / 删除；模型配置、连接、会话与记忆都存在 `~/.agentdb/`。
