# 04 · 结构设计

适用版本：0.1.0 ｜ 更新于 2026-10-10

## 数据库设计器

在左侧数据库节点的菜单里选「新建数据库 / 编辑数据库」，弹窗按页签组织：

| 页签 | 内容 |
| --- | --- |
| 常规 | 数据库名（改名）、属主、字符集、排序规则、模板、编码、表空间等，按引擎只出现该引擎支持的项 |
| 扩展 | 仅 PostgreSQL / PgVector：列出可用与已装扩展，可安装 / 卸载 |
| 注释 | 数据库级注释 |
| SQL 预览 | 保存前先看将要执行的语句 |

细节：

- 候选值（属主、字符集、排序规则、模板、表空间、编码）全部来自服务端真实查询，并且都是**可键入筛选的下拉**；排序规则会随字符集联动收窄。
- 建库后不可修改的项在编辑态会置灰，悬停说明原因；具体清单由后端按引擎返回，不在前端硬编码。
- 执行前做名称与标识符校验，不合法直接报错而不是生成半条语句。

## 可视化建表

表 / 索引 / 集合的创建入口在树顶部的 `+`，按引擎切换形态：

- **关系引擎**：字段网格（名称、类型、长度、可空、主键、默认值、注释），可增删行、拖不动就按顺序排列；类型是「下拉 + 长度格」组合，MySQL 下 `VARCHAR/CHAR/BIT/BINARY/VARBINARY/ENUM/SET` 这类必须带长度的类型会自动补一个常用长度，避免拼出语法错的语句。
- **Elasticsearch**：索引名、分片数、副本数与 mapping JSON（带样例模板与格式校验）。
- **MongoDB**：集合名与校验规则。
- **Qdrant**：集合名、向量维度与距离函数（Cosine / Euclid / Dot / Manhattan，带中文说明）。

创建前都能查看将要执行的 DDL。

## 字段编辑

「结构」页签里每个字段都可编辑：改名、改类型、改可空、改默认值、改注释、调顺序（引擎支持时）。生成的语句按引擎方言拼装，MySQL 走 `MODIFY/CHANGE`，PostgreSQL 走 `ALTER COLUMN` + `COMMENT ON COLUMN`，SQLite 走重建表路径。删除字段有二次确认。

MongoDB / Elasticsearch 没有「列」的概念，这里的字段管理对应各自的原生做法：Mongo 用 `$set / $rename / $unset` 落到全量文档，ES 通过 `PUT /<index>/_mapping` 新增字段——**已存在字段的类型不能改**，界面不给这个按钮，并提示改用重建索引。

## 索引与外键

- 索引：名称、唯一性、字段用**按选择顺序**组成的芯片（点芯片可移除，顺序即联合索引顺序，不需要手写逗号串），字段下拉的副标题显示类型便于挑。
- 外键：约束名、本表字段、引用表、引用字段、`ON DELETE` / `ON UPDATE`。引用表与引用字段是**联动下拉**——选表后实时拉该表字段，切换表会清空已选字段并丢弃过期响应；候选动作按引擎给出（MySQL 与 PostgreSQL 的取值集合不同），留空表示用数据库默认。
- SQLite 不能 `ALTER TABLE ADD FOREIGN KEY`，界面直接说明限制与替代做法（建表时声明或重建表）。
- 删除索引 / 外键有二次确认，执行后回读列表，让结果立刻可见。
