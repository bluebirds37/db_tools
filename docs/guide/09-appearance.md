# 09 · 外观与字体

适用版本：0.1.0 ｜ 更新于 2026-10-14

## 主题

顶栏的太阳 / 月亮图标切换深色与浅色，切换用一次快照交叉淡化（不支持该能力的运行时就直接换）。主题选择记在本机。

**窗口标题栏跟着主题走**：深色主题下标题栏与窗口按钮一起变暗（Windows 走 DWM 的 immersive dark mode，macOS 走窗口外观），不会再出现「白条压在深色界面上」；切回浅色时标题栏也回到亮色。窗口初始主题在 `tauri.conf.json` 里定为深色，所以启动第一帧就是暗的。

## 字体：一个设置管全部

「设置 → 外观与字体」里只有**一个字体设置**：字体 + 字号，界面与代码共用，不再有「界面字号 / 代码字号」两个旋钮。

- **字体**：可筛选下拉，候选按用途标注（界面优先 / 等宽 / 等宽中文），包含 Segoe UI、微软雅黑、苹方、鸿蒙黑体、思源黑体、更纱黑体、Inter，以及 JetBrains Mono、Cascadia Code / Mono、Consolas、思源等宽、SF Mono、Menlo；选「手动输入字体名…」可填本机已装的任意字体；「恢复默认」一键回到跟随系统 + 13px。
- **字号**：滑条与数字框联动，范围 11–24，超出范围会被夹回。
- **生效范围**：正文、数据表格、SQL 编辑器、命令 / REST 输出、代码类文本全部跟着这一份设置走；标签、徽标这类界面小字保持固定字号，以免密集布局被撑坏。
- **健壮性**：选中的字体本机没装时自动回退到系统字体栈，界面不会崩；输入字体名时会过滤掉能破坏样式的字符。

改动即时生效并记在本机，不需要重启。

## 动效

统一的时间与缓动变量（`--dur-1/2/3`、`--ease-out`、`--ease-spring`）驱动：弹窗弹入、页签切换、列表逐项错峰进入、下拉面板淡入上移、通知条滑入、进度条扫光、骨架屏微光。

系统开启「减少动态效果」（`prefers-reduced-motion`）时，以上动画整体降级为直接呈现，不做位移与淡入。

## 状态反馈

| 场景 | 表现 |
| --- | --- |
| 加载 | 右侧内容区显示加载页（含等待秒数与「重新读取」），列表用骨架屏 |
| 空 | 空状态插画 + 一句下一步该做什么 |
| 执行中 | 对话框内进度条 + 按钮文案变为「处理中…」并禁用 |
| 完成 | 顶部通知条显示后端返回的结论（含结果数字），8 秒后自动消失，可点右侧关闭 |
| 失败 | 通知条与错误横幅显示原始错误文本，同时写入日志 |
