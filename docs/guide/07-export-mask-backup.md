# 07 · 导出与备份

适用版本：0.1.0 ｜ 更新于 2026-10-10

## 数据导出（CSV / Excel）

入口：顶栏「数据导出」，或表工具条的「导出」。弹窗字段：

| 字段 | 说明 |
| --- | --- |
| 格式 | CSV（带 BOM，Excel 打开不乱码）或 Excel（SpreadsheetML 2003，`.xls`） |
| 脱敏规则 | 见下一节，两种格式共用同一套规则 |
| 最大行数 | `0` 或 `-1` = 全部行 |
| 保存到 | 可直接输入路径，或点「选择」用系统保存对话框 |

导出的内容来自当前选中表（或你改过的查询语句），执行后通知条给出：文件路径、行数、字节数、**实际生效的脱敏列**；如果某条规则写的列在结果里不存在，会明确列出「这些列在结果集中不存在，未生效」。

## 列级脱敏

一行一条规则：**列 + 方式（+ 参数）**，全部是下拉与数字框，不需要手敲语法。

| 方式 | 效果 |
| --- | --- |
| 全部掩码 | `******`（长度按原值，最多 12 个 `*`） |
| 保留前后几位 | 自定义「留前 / 留后」，中间掩码；长度不足时整串掩码 |
| 邮箱 | `a***@qq.com`；不是合法邮箱时退化为全掩码 |
| 手机号 | 自动去掉分隔符后按 `138****5678` 处理 |
| 身份证 | 18 位 → 前 6 后 4；15 位 → 前 6 后 3 |
| 银行卡 | 只保留后 4 位 |
| 姓名 | 只保留首字 |
| 哈希 | 同值同码的定长摘要，便于跨文件对得上（**非密码学强度**，只用于匿名化） |
| 固定替换文本 | 整列换成你指定的文本 |
| 置为空 | 值清空（NULL 仍然保持 NULL，不会伪装成空字符串） |

规则细节：

- **列名匹配不区分大小写**，支持 `表.列` 与带引号 / 反引号的写法；
- 命中列的每个值在写入文件前完成改写，NULL 不动；
- 列来自当前表的真实字段下拉（可键入筛选），读不到字段时可以「手动输入列名」；
- 「识别敏感列」按列名批量生成规则（手机 / 邮箱 / 身份证 / 银行卡 / 姓名），识别不到会说明原因；
- 规则会记在本机，下次打开导出对话框还在；
- 非字符串值（数字、日期、JSON）会被转成文本再掩码——这是脱敏的预期行为。

脱敏只作用于**导出文件**。备份与同步是刻意没有接脱敏的：那两条链路要求与源库一致。

## 数据库备份（SQL 转储）

入口：顶栏「数据库备份」（整库）或表工具条「转储表」。

- 可选 表结构 / 数据（可只选其一）；
- 整库备份跳过视图与物化视图；
- 文件名默认带时间戳（`<库名>_backup_2026-10-10T06-30-00.sql`），避免反复覆盖；
- 行数上限同样是 `0 / -1` = 全部行，逐页取数拼 INSERT；
- 单表转储在文件头写入来源与时间注释，尾部写 `-- rows: N`；
- 某张表转储失败不会中断整库，会在该表位置留下 `-- skip <表>: <原因>` 注释。

> 这是应用内的逻辑转储（跨引擎可读的 INSERT 脚本），不是 `mysqldump` / `pg_dump` 那种物理备份；需要原生格式时请直接用对应客户端工具。
