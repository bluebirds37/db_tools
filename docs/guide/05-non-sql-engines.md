# 05 · 非关系引擎

适用版本：0.1.0 ｜ 更新于 2026-10-10

这些引擎不套一层「假 SQL」，页签名称、输入语法、结构页操作都按各自原生能力给。

## Redis（页签：命令 / 结构）

| 输入 | 行为 |
| --- | --- |
| `KEYS user:*` 或直接写 `user:*` | 以表格列出匹配的键（含类型、TTL） |
| `GET k` / `HGETALL k` / `LRANGE k 0 20` / `SMEMBERS k` / `ZRANGE k 0 20 WITHSCORES` / `TYPE k` / `TTL k` | 执行单条命令并按类型渲染结果（`OK`、`(nil)`、编号数组、`k: v` 映射） |
| `SET k v EX 300` / `HSET k f v` / `DEL k` | 写命令，执行后按主键回读该键显示当前值 |
| `DBSIZE` / `INFO` / `INFO memory` | 服务信息 |

- 逻辑库通过连接的「默认 DB 索引」下拉（`db0…db15`）选择，命令按当前库路由。
- 插入需要 `key` 字段：Redis 没有表，键名就是主键。
- 「常用操作」按 读 / 写 / 库信息 分组，点一下填进输入框。

## Elasticsearch（页签：REST / 映射）

- 语法：`METHOD /path [json]`，请求体可以跟在同行，也可以**另起一行写多行 / 美化过的 JSON**；尾随的非 JSON 文字按注释忽略，但看着像 JSON 却解析不动时会明确报错而不是偷偷丢掉请求体。
- 简写：只写索引名 → `GET /<index>/_search`；`索引|{"query":{...}}` → 带条件的查询。
- 写入后自动刷新索引，所以新记录立刻出现在结果里。
- 数据网格里 `_id`、`_score` 等是**元字段**：只用于定位文档，输入框置灰且不会写进 `_source`（否则 ES 会以 `mapper_parsing_exception` 拒绝整条更新）。改文档 id 请新建文档。
- 「常用操作」分 5 组共 28 条：集群、查询、写入、映射、索引管理；`{name}` 会替换成当前选中的索引。删除索引、按条件删除等破坏性条目红色描边。
- 结构页是「映射」：查看 mapping、新增字段、字段能力（`_field_caps`）。已存在字段类型不可改，替代做法是重建索引（清单里有 `_reindex` 条目）。

## Qdrant（页签：REST / 结构）

- 与 ES 同一套 REST 解析（`METHOD /path [json]`，多行 body 可用）。
- 简写：只写集合名 → 滚动列出点位。
- 常用操作分 集合 / 点位：集合列表、详情、计数、分片信息；滚动取点、向量检索、按 id 取点、删除点位。

## MongoDB（页签：查询 / 字段）

| 输入 | 行为 |
| --- | --- |
| `orders\|{"status":1}` | 按过滤条件查询集合 |
| `db.admin.{"ping":1}` | 对指定库执行 runCommand |

- 结构页是「字段」：从采样文档推断字段与类型，可新增 / 改名 / 删除字段（落到 `$set / $rename / $unset`），也支持集合级索引管理。
- `ObjectId` 与 24 位十六进制字符串双向还原，所以按 id 编辑、删除都能定位到文档。

## 统一的行数上限

这些引擎的数据出口与导出、同步共用同一套语义：填 `0` 或 `-1` 表示不限制，逐页取数不整表驻留。详见 [06](06-sync-and-migration.md)。
