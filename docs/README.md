## 目录约定

```
docs/
├── README.md            # 本索引
├── guide/               # 主题细册，一篇一件事
├── images/              # 文档配图，命名 NN-英文短名.png
└── screenshots/         # 早期版本截图存档，不在文档中引用
```

## 写作规范

- **语言**：文档默认中文；入口文档保持 `README.md`（中）+ `README.en.md`（英）两份对等完整，改功能时两份一起改。
- **命名**：`guide/` 下用 `NN-kebab-case.md`，编号即阅读顺序；新增页面必须在本索引表格里登记。
- **图片**：统一放 `images/`，`NN-` 前缀与引用它的文档编号对应；截图一律用合成种子数据，不得出现真实库名、表名、字段名或本机地址。
- **准确性**：只写代码里真实存在的行为（按钮位置、默认值、语义、限制）；引擎做不到的事要写清限制与替代做法，不写「不支持」就结束。
- **口径一致**：跨功能的统一语义（例如行数上限 `0 / -1` = 全部行）在总览处说明一次，其他页面引用而不重复定义。
